Helios Space — standalone website
================================

This zip is a complete static website. No install, no server, no account.

Open the site
-------------
1. Unzip this folder.
2. Open index.html in Chrome, Edge, Firefox, or Safari.
3. Or drop the unzipped folder onto Netlify Drop, Surge, Cloudflare Pages,
   or GitHub Pages for a free public URL (like Base44's *.base44.app).

Free domain options
-------------------
- GitHub Pages:  https://<user>.github.io/<repo>/
- Netlify:       https://<name>.netlify.app
- Surge:         https://<name>.surge.sh
- Cloudflare:    https://<name>.pages.dev

These are free subdomains, the same idea as Base44 publishing a site
to a free *.base44.app address.
